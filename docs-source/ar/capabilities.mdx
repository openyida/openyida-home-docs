تلخص هذه الصفحة قدرات OpenYida الحالية لمستخدمي Yida و AI Agents، مع أوامر `openyida` المستخدمة عادة في كل سيناريو.

<Note>
استخدم `openyida agent-capabilities --summary-json` كفحص خفيف افتراضي. استخدم `openyida agent-capabilities --json` فقط عند الحاجة إلى تشخيص كامل أو command Manifest أو metadata للصلاحيات أو تفاصيل خام لفشل تسجيل الدخول.
</Note>

## الأساسيات

| الميزة | الأمر |
|---|---|
| فحص Agent خفيف | `openyida agent-capabilities --summary-json` |
| تشخيص Agent كامل | `openyida agent-capabilities --json` |
| فحص البيئة وتسجيل الدخول | `openyida env` / `openyida env --json` |
| إدارة environment profiles | `openyida env <setup\|list\|show\|switch\|add\|remove>` |
| تسجيل دخول OAuth token | `openyida login` |
| تسجيل الدخول بعنوان URL مستهدف | `openyida login <target-url>` |
| حالة token وتحديثه | `openyida auth <status\|login\|refresh\|logout>` |
| تبديل المؤسسة | `openyida org <list\|switch> [--corp-id <corpId>]` |
| Command Manifest | `openyida commands --json` |

## التطبيقات والنماذج

| الميزة | الأمر |
|---|---|
| عرض التطبيقات | `openyida app-list [--size N]` |
| إنشاء أو تحديث التطبيقات | `openyida create-app ...` / `openyida update-app ...` |
| استيراد أو تصدير حزم الترحيل | `openyida export ...` / `openyida import ...` |
| إنشاء أو تحديث أو patch أو التحقق من النماذج أو ربطها | `openyida create-form <create\|update\|patch\|rule\|validation\|bind-datasource> ...` |
| الاستعلام عن النماذج و Schemas | `openyida list-forms ...` / `openyida get-schema ...` |
| إدارة مجموعات التنقل | `openyida nav-group <list\|create\|rename\|delete\|move\|order\|hide\|show> ...` |
| إدارة الصلاحيات | `openyida app-permission ...` / `openyida get-permission ...` / `openyida save-permission ...` |

## الصفحات والبيانات والعمليات

| الميزة | الأمر |
|---|---|
| إنشاء صفحات العرض | `openyida create-page <appType> "<name>"` |
| توليد وفحص وتجميع ونشر كود الصفحة | `openyida generate-page ...` / `openyida check-page ...` / `openyida compile ...` / `openyida publish ...` |
| نشر صفحات Code Canvas | `openyida publish <src.canvas.jsx> <appType> <formUuid>` |
| قراءة أو تعديل بيانات form/process/task/subform | `openyida data <action> <resource> ...` |
| إنشاء وتهيئة نماذج العمليات | `openyida create-process ...` / `openyida configure-process ...` |
| الاستعلام عن المهام والتفويضات | `openyida task-center ...` / `openyida agent-center ...` |

## التكامل والتقارير والأدوات

| الميزة | الأمر |
|---|---|

| HTTP connectors | `openyida connector <list\|create\|detail\|add-action\|test\|smart-create> ...` |
| أتمتة التكامل | `openyida integration <create\|list\|enable\|disable\|check\|diagnose> ...` |

| AI والموارد والصيغ وتحويل PRD | `openyida ai ...` / `openyida asset ...` / `openyida formula evaluate ...` / `openyida flash-to-prd ...` |
| الإعداد المحلي والتشخيص والدفعات | `openyida copy` / `openyida doctor` / `openyida batch` |
| MCP و A2A و local bridge | `openyida mcp` / `openyida a2a ...` / `openyida bridge start ...` |
| الإخراج الهادئ وفحص التحديثات | `openyida --quiet ...` / `YIDA_QUIET=1` / `OPENYIDA_SKIP_UPDATE_CHECK=1` |

## الصفحات المخصصة وسلسلة النشر و i18n

| القدرة | الأمر |
|---|---|
| إنشاء صفحة Code Canvas للأعمال من مواصفة صفحة | `openyida generate-page <template> --spec <page-spec.json> --output project/pages/src/<name>.canvas.jsx --compile` |
| تطبيق ملف سمة ونطاق السمة أثناء الإنشاء | `openyida generate-page ... --theme-profile <profile> --theme-scope <page\|global>` |
| إنشاء صفحات عينة Code Canvas | `openyida sample yida-canvas-custom-page <sample> --output project/pages/src/<name>.canvas.jsx` |
| إنشاء عينات صفحة مخصصة كلاسيكية | `openyida sample yida-custom-page <sample> --output project/pages/src/<name>.oyd.jsx` |
| فحص كود الصفحة وتطبيعه قبل النشر | `openyida check-page <src>` / `openyida build-page <src> --write` |
| قراءة إعدادات الصفحة الحالية قبل استبدال تغييرات المصمم | `openyida get-form-config <appType> <formUuid> --json` / `openyida get-schema <appType> <formUuid>` |
| نشر الصفحات المخصصة الكلاسيكية | `openyida publish project/pages/src/<name>.oyd.jsx <appType> <formUuid>` |
| نشر صفحات Code Canvas | `openyida publish project/pages/src/<name>.canvas.jsx <appType> <formUuid> --canvas` |
| تشغيل فحص صحة مباشرة بعد النشر | `openyida publish <src> <appType> <formUuid> --health-check` |
| تحديث إعدادات الصفحة أو النموذج بعد النشر | `openyida update-form-config <appType> <formUuid> ...` |
| إعداد الوصول العام والتنقل المخفي ومداخل المشاركة | `openyida verify-short-url ...` / `openyida save-share-config ...` / `openyida get-page-config ...` |
| رفع أصول الصفحة إلى CDN | `openyida cdn-upload <asset-path>` |
| قراءة إعدادات CDN وتحديث الموارد | `openyida cdn-config` / `openyida cdn-refresh ...` |
| فحص وترقية حزمة OpenYida CLI | `openyida update` / `npm install -g openyida@latest` |
| إدارة حزم لغات التطبيق | `openyida i18n <overview\|config\|languages\|list\|upsert\|batch-upsert\|bind\|delete\|translate\|translate-all\|upgrade> ...` |
| تشغيل CLI بحزمة لغة محددة | `OPENYIDA_LANG=<locale> openyida ...` / `OPENYIDA_LOCALE_DIR=<dir> openyida ...` |

<Warning>
لم تعد flags القديمة لتسجيل الدخول مثل `--qr` و `--browser` و `--codex` و `--qoder` مدعومة. استخدم OAuth token login.
</Warning>
