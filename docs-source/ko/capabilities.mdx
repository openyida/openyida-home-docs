이 목록은 Yida 사용자와 AI Agent를 위해 OpenYida의 주요 기능과 일반적으로 사용하는 `openyida` 명령을 시나리오별로 요약합니다.

<Note>
기본 경량 사전 점검에는 `openyida agent-capabilities --summary-json`을 사용합니다. 전체 진단, 명령 Manifest, 권한 메타데이터 또는 원시 로그인 실패 사유가 필요할 때만 `openyida agent-capabilities --json`을 사용하세요.
</Note>

## 기본 작업

| 기능 | 명령 |
|---|---|
| 경량 Agent 사전 점검 | `openyida agent-capabilities --summary-json` |
| 전체 Agent 진단 | `openyida agent-capabilities --json` |
| 환경 및 로그인 상태 확인 | `openyida env` / `openyida env --json` |
| 환경 profile 관리 | `openyida env <setup\|list\|show\|switch\|add\|remove>` |
| OAuth token 로그인 | `openyida login` |
| 대상 URL로 로그인 | `openyida login <target-url>` |
| token 상태 및 갱신 | `openyida auth <status\|login\|refresh\|logout>` |
| 조직 전환 | `openyida org <list\|switch> [--corp-id <corpId>]` |
| 명령 Manifest | `openyida commands --json` |

## 앱과 폼

| 기능 | 명령 |
|---|---|
| 앱 목록 조회 | `openyida app-list [--size N]` |
| 앱 생성 또는 업데이트 | `openyida create-app ...` / `openyida update-app ...` |
| 마이그레이션 패키지 가져오기/내보내기 | `openyida export ...` / `openyida import ...` |
| 폼 생성, 업데이트, patch, 검증, 데이터소스 바인딩 | `openyida create-form <create\|update\|patch\|rule\|validation\|bind-datasource> ...` |
| 폼과 Schema 조회 | `openyida list-forms ...` / `openyida get-schema ...` |
| 앱 내비게이션 그룹 관리 | `openyida nav-group <list\|create\|rename\|delete\|move\|order\|hide\|show> ...` |
| 앱 및 폼 권한 관리 | `openyida app-permission ...` / `openyida get-permission ...` / `openyida save-permission ...` |

## 페이지, 데이터, 프로세스

| 기능 | 명령 |
|---|---|
| 표시 페이지 생성 | `openyida create-page <appType> "<name>"` |
| 페이지 코드 생성, 검사, 컴파일, 게시 | `openyida generate-page ...` / `openyida check-page ...` / `openyida compile ...` / `openyida publish ...` |
| Code Canvas 페이지 게시 | `openyida publish <src.canvas.jsx> <appType> <formUuid>` |
| 폼/프로세스/작업/서브폼 데이터 처리 | `openyida data <action> <resource> ...` |
| 프로세스 폼 생성 및 설정 | `openyida create-process ...` / `openyida configure-process ...` |
| 작업 센터와 위임 관리 | `openyida task-center ...` / `openyida agent-center ...` |

## 통합, 리포트, 유틸리티

| 기능 | 명령 |
|---|---|
| 리포트와 대시보드 | `openyida create-report ...` / `openyida append-chart ...` |
| HTTP 커넥터 | `openyida connector <list\|create\|detail\|add-action\|test\|smart-create> ...` |
| 통합 자동화 | `openyida integration <create\|list\|enable\|disable\|check\|diagnose> ...` |
| DingTalk 문서와 DWS CLI | `openyida read-dingtalk-doc ...` / `openyida dws <command>` |
| AI, 자산, 수식, PRD 변환 | `openyida ai ...` / `openyida asset ...` / `openyida formula evaluate ...` / `openyida flash-to-prd ...` |
| 로컬 초기화, 진단, 배치 실행 | `openyida copy` / `openyida doctor` / `openyida batch` |
| MCP, A2A, 로컬 bridge | `openyida mcp` / `openyida a2a ...` / `openyida bridge start ...` |
| 조용한 출력 및 업데이트 확인 | `openyida --quiet ...` / `YIDA_QUIET=1` / `OPENYIDA_SKIP_UPDATE_CHECK=1` |

## 사용자 정의 페이지, 게시 체인 및 다국어

| 기능 | 명령 |
|---|---|
| 페이지 스펙으로 업무용 Code Canvas 페이지 생성 | `openyida generate-page <template> --spec <page-spec.json> --output project/pages/src/<name>.canvas.jsx --compile` |
| 생성 시 테마 프로필과 적용 범위 지정 | `openyida generate-page ... --theme-profile <profile> --theme-scope <page\|global>` |
| Code Canvas 샘플 페이지 생성 | `openyida sample yida-canvas-custom-page <sample> --output project/pages/src/<name>.canvas.jsx` |
| 클래식 사용자 정의 페이지 샘플 생성 | `openyida sample yida-custom-page <sample> --output project/pages/src/<name>.oyd.jsx` |
| 게시 전 페이지 코드 검사 및 정규화 | `openyida check-page <src>` / `openyida build-page <src> --write` |
| 디자이너 변경을 덮어쓰기 전에 온라인 설정 읽기 | `openyida get-form-config <appType> <formUuid> --json` / `openyida get-schema <appType> <formUuid>` |
| 클래식 사용자 정의 페이지 게시 | `openyida publish project/pages/src/<name>.oyd.jsx <appType> <formUuid>` |
| Code Canvas 페이지 게시 | `openyida publish project/pages/src/<name>.canvas.jsx <appType> <formUuid> --canvas` |
| 게시 직후 health check 실행 | `openyida publish <src> <appType> <formUuid> --health-check` |
| 게시 후 페이지 또는 폼 설정 업데이트 | `openyida update-form-config <appType> <formUuid> ...` |
| 공개 접근, 숨김 내비게이션, 공유 진입점 설정 | `openyida verify-short-url ...` / `openyida save-share-config ...` / `openyida get-page-config ...` |
| 페이지 assets를 CDN에 업로드 | `openyida cdn-upload <asset-path>` |
| CDN 설정 확인 및 리소스 새로고침 | `openyida cdn-config` / `openyida cdn-refresh ...` |
| OpenYida CLI 패키지 확인 및 업그레이드 | `openyida update` / `npm install -g openyida@latest` |
| 앱 언어팩 관리 | `openyida i18n <overview\|config\|languages\|list\|upsert\|batch-upsert\|bind\|delete\|translate\|translate-all\|upgrade> ...` |
| 선택한 언어팩으로 CLI 실행 | `OPENYIDA_LANG=<locale> openyida ...` / `OPENYIDA_LOCALE_DIR=<dir> openyida ...` |

<Warning>
`--qr`, `--browser`, `--codex`, `--qoder` 같은 기존 로그인 플래그는 더 이상 지원되지 않습니다. OAuth token 로그인을 사용하세요.
</Warning>
