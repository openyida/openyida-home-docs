Diese Liste fasst die aktuellen OpenYida-Funktionen für Yida-Nutzer und AI Agents zusammen, inklusive der typischen `openyida`-Befehle.

<Note>
Nutzen Sie `openyida agent-capabilities --summary-json` als standardmäßigen leichten Preflight. `openyida agent-capabilities --json` ist nur für vollständige Diagnosen, Command Manifest, Berechtigungsmetadaten oder rohe Login-Fehlerdetails gedacht.
</Note>

## Grundlagen

| Funktion | Befehl |
|---|---|
| Leichter Agent-Preflight | `openyida agent-capabilities --summary-json` |
| Vollständige Agent-Diagnose | `openyida agent-capabilities --json` |
| Umgebung und Login prüfen | `openyida env` / `openyida env --json` |
| Environment-Profile verwalten | `openyida env <setup\|list\|show\|switch\|add\|remove>` |
| OAuth-token Login | `openyida login` |
| Login mit Ziel-URL | `openyida login <target-url>` |
| Token-Status und Refresh | `openyida auth <status\|login\|refresh\|logout>` |
| Organisation wechseln | `openyida org <list\|switch> [--corp-id <corpId>]` |
| Command Manifest | `openyida commands --json` |

## Apps und Formulare

| Funktion | Befehl |
|---|---|
| Apps auflisten | `openyida app-list [--size N]` |
| Apps erstellen oder aktualisieren | `openyida create-app ...` / `openyida update-app ...` |
| Migrationspakete importieren/exportieren | `openyida export ...` / `openyida import ...` |
| Formulare erstellen, aktualisieren, patchen, validieren oder binden | `openyida create-form <create\|update\|patch\|rule\|validation\|bind-datasource> ...` |
| Formulare und Schemas abfragen | `openyida list-forms ...` / `openyida get-schema ...` |
| App-Navigation verwalten | `openyida nav-group <list\|create\|rename\|delete\|move\|order\|hide\|show> ...` |
| App- und Formularberechtigungen verwalten | `openyida app-permission ...` / `openyida get-permission ...` / `openyida save-permission ...` |

## Seiten, Daten und Prozesse

| Funktion | Befehl |
|---|---|
| Display-Seiten erstellen | `openyida create-page <appType> "<name>"` |
| Seitencode generieren, prüfen, kompilieren und veröffentlichen | `openyida generate-page ...` / `openyida check-page ...` / `openyida compile ...` / `openyida publish ...` |
| Code Canvas-Seiten veröffentlichen | `openyida publish <src.canvas.jsx> <appType> <formUuid>` |
| Formular-/Prozess-/Task-/Subform-Daten lesen oder ändern | `openyida data <action> <resource> ...` |
| Prozessformulare erstellen und konfigurieren | `openyida create-process ...` / `openyida configure-process ...` |
| Globale Aufgaben und Delegationen abfragen | `openyida task-center ...` / `openyida agent-center ...` |

## Integrationen, Reports und Tools

| Funktion | Befehl |
|---|---|
| Reports und Dashboards | `openyida create-report ...` / `openyida append-chart ...` |
| HTTP-Connectoren | `openyida connector <list\|create\|detail\|add-action\|test\|smart-create> ...` |
| Integrationsautomatisierung | `openyida integration <create\|list\|enable\|disable\|check\|diagnose> ...` |
| DingTalk-Dokumente und DWS CLI | `openyida read-dingtalk-doc ...` / `openyida dws <command>` |
| AI, Assets, Formeln und PRD-Konvertierung | `openyida ai ...` / `openyida asset ...` / `openyida formula evaluate ...` / `openyida flash-to-prd ...` |
| Lokale Einrichtung, Diagnose und Batch | `openyida copy` / `openyida doctor` / `openyida batch` |
| MCP, A2A und lokaler Bridge | `openyida mcp` / `openyida a2a ...` / `openyida bridge start ...` |
| Leise Ausgabe und Update-Checks | `openyida --quiet ...` / `YIDA_QUIET=1` / `OPENYIDA_SKIP_UPDATE_CHECK=1` |

## Benutzerdefinierte Seiten, Veröffentlichungskette und i18n

| Funktion | Befehl |
|---|---|
| Business-Code-Canvas-Seite aus einer Seitenspezifikation generieren | `openyida generate-page <template> --spec <page-spec.json> --output project/pages/src/<name>.canvas.jsx --compile` |
| Theme-Profil und Gültigkeitsbereich beim Generieren anwenden | `openyida generate-page ... --theme-profile <profile> --theme-scope <page\|global>` |
| Code-Canvas-Beispielseiten erzeugen | `openyida sample yida-canvas-custom-page <sample> --output project/pages/src/<name>.canvas.jsx` |
| Klassische Custom-Page-Beispiele erzeugen | `openyida sample yida-custom-page <sample> --output project/pages/src/<name>.oyd.jsx` |
| Seitencode vor der Veröffentlichung prüfen und normalisieren | `openyida check-page <src>` / `openyida build-page <src> --write` |
| Live-Konfiguration vor dem Überschreiben von Designer-Änderungen lesen | `openyida get-form-config <appType> <formUuid> --json` / `openyida get-schema <appType> <formUuid>` |
| Klassische benutzerdefinierte Seiten veröffentlichen | `openyida publish project/pages/src/<name>.oyd.jsx <appType> <formUuid>` |
| Code-Canvas-Seiten veröffentlichen | `openyida publish project/pages/src/<name>.canvas.jsx <appType> <formUuid> --canvas` |
| Direkt nach der Veröffentlichung einen Health Check ausführen | `openyida publish <src> <appType> <formUuid> --health-check` |
| Seiten- oder Formularkonfiguration nach der Veröffentlichung aktualisieren | `openyida update-form-config <appType> <formUuid> ...` |
| Öffentlichen Zugriff, ausgeblendete Navigation und Share-Einstiege konfigurieren | `openyida verify-short-url ...` / `openyida save-share-config ...` / `openyida get-page-config ...` |
| Seiten-Assets zum CDN hochladen | `openyida cdn-upload <asset-path>` |
| CDN-Konfiguration lesen und Ressourcen aktualisieren | `openyida cdn-config` / `openyida cdn-refresh ...` |
| OpenYida-CLI-Paket prüfen und aktualisieren | `openyida update` / `npm install -g openyida@latest` |
| App-Sprachpakete verwalten | `openyida i18n <overview\|config\|languages\|list\|upsert\|batch-upsert\|bind\|delete\|translate\|translate-all\|upgrade> ...` |
| CLI mit einem ausgewählten Sprachpaket ausführen | `OPENYIDA_LANG=<locale> openyida ...` / `OPENYIDA_LOCALE_DIR=<dir> openyida ...` |

<Warning>
Alte Login-Flags wie `--qr`, `--browser`, `--codex`, `--qoder` werden nicht mehr unterstützt. Verwenden Sie OAuth-token Login.
</Warning>
