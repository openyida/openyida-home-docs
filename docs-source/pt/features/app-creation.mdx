## Posicionamento

Use o OpenYida para transformar requisitos em um app Yida utilizável com apps, páginas, formulários, fluxos e publicação.

## Tarefas típicas

- OpenYida agent-capabilities --summary-json
- openyida create-app
- openyida create-form
- openyida create-process
- openyida publish

## Dicas de uso

Start from requirements, confirm the target organization, then create resources and verify the final access link.

## Tabela de capacidades

| Etapa | O que confirmar | Comando / capacidade |
| --- | --- | --- |
| Preflight | Login state, organization, target environment | `openyida agent-capabilities --summary-json` |
| App shell | App name, business scope, owner organization | `openyida create-app` |
| Business objects | Forms, pages, workflows, navigation plan | `openyida create-form`, `openyida create-process` |
| Publishing | Page publish result and accessible URL | `openyida publish` |
| Read-back | Created resource IDs and final state | query / inspect commands |

## Comandos copiáveis

```bash
openyida agent-capabilities --summary-json
openyida create-app --help
openyida create-form --help
openyida create-process --help
openyida publish --help
```

## Checklist de aceite

- The target organization and environment are confirmed.
- Forms, pages, workflows, and navigation match the requirement.
- Published pages return accessible links.
- Key resource IDs are listed for later maintenance.
- The AI Agent reports what was created and what still needs manual confirmation.
