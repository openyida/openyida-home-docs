## Posicionamento

Gerencie navegação, i18n, permissões, ciclo de vida e informações da organização com OpenYida.

## Tarefas típicas

- openyida nav-group
- openyida i18n
- openyida app-permission
- openyida app-online / app-offline
- openyida basic-info

## Dicas de uso

For permissions, lifecycle, and public access changes, ask the Agent to show the affected objects before applying changes.

## Tabela de capacidades

| O que confirmar | Comando / capacidade | Notas |
| --- | --- | --- |
| Navigation groups | `openyida nav-group` | List current navigation before changing it. |
| Multilingual text | `openyida i18n` | Cover page titles, buttons, fields, and messages. |
| App permissions | `openyida app-permission` | Search users and confirm roles before update. |
| Lifecycle state | `openyida app-online`, `openyida app-offline` | Explain impact scope first. |
| Organization basics | `openyida basic-info`, `openyida corp-manager` | Use for capacity, domain, and organization context. |

## Comandos copiáveis

```bash
openyida nav-group --help
openyida i18n --help
openyida app-permission --help
openyida app-online --help
openyida app-offline --help
openyida basic-info --help
openyida corp-manager --help
```

## Modelo de prompt AI Agent

```
Manage this Yida app. First inspect the current navigation, i18n, permissions, lifecycle state, and organization basics. Then propose the exact changes and affected objects. Only apply permission, lifecycle, or public-access changes after confirming the impact scope.

Target app: [app name or appType]
Management task: [describe task]
```

## Checklist de aceite

- Current state is listed before changes.
- Permission and lifecycle changes include impact scope.
- Navigation and i18n updates are read back after execution.
- The final result includes changed objects and follow-up risks.
