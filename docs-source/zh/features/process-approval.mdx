## 适用场景

流程审批用于创建请假、采购、报销、合同、入职等需要多角色协作的审批链路。OpenYida 可以帮助 AI Agent 建立流程表单、审批节点、流转规则和发布验证。

## 设计要点

- 先说明流程发起人、审批角色、归档节点和异常退回规则。
- 表单字段要能支撑流程判断，例如金额、部门、申请类型和审批状态。
- 配置后需要确认流程是否发布，并回读流程页面或关键配置。
- 高影响流程修改前，让 Agent 先列出将要调整的节点和影响范围。

## 常用提示词

```
帮我创建一个采购审批流程，包含申请人提交、直属主管审批、财务复核和归档。完成后告诉我流程是否已发布。
```

<Note>
流程审批涉及真实业务流转，修改线上流程前建议先确认目标应用、目标表单和审批节点。
</Note>

## 能力速查

| 阶段 | 关注点 | 命令 / 能力 |
| --- | --- | --- |
| 流程模型 | 发起人、审批人、归档节点、退回规则 | requirement analysis |
| 流程表单 | 用于流转和审批判断的字段 | `openyida create-process` |
| 审批规则 | 审批角色、分支和条件 | `openyida process-rule` |
| 发布状态 | 流程是否已发布 | publish / inspect commands |
| 节点和流程状态 | 回读结果 | read-back result |

## 可复制命令

```bash
openyida create-process --help
openyida process-rule --help
openyida agent-capabilities --summary-json
```

## AI Agent 提示词模板

```
创建一个宜搭审批流程。请先列出发起人、表单字段、审批节点、审批人规则、分支条件、归档节点和退回规则；再使用 OpenYida 创建流程、配置审批规则，确认是否已发布，最后回报节点列表和资源 ID。

流程需求：[描述流程]
```

## 验收清单

- 发起人、审批人和归档节点清晰。
- 流程判断所需字段已存在。
- 审批规则已配置并验证。
- 已回报发布状态和关键资源 ID。
