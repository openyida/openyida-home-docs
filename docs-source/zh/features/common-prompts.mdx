OpenYida 适合直接交给 AI Agent 使用。你可以复制下面的提示词到千问办公、Codex、Claude Code、Cursor 等工具中，让 Agent 自动检查环境、选择命令、执行操作，并在完成后说明结果。

<Note>
涉及删除、权限变更、应用启停、公开访问等有影响的操作时，请让 Agent 先说明将要修改的对象和范围，再继续执行。
</Note>

---

## 环境检查与登录

```
请先检查 OpenYida 是否可用：运行 openyida agent-capabilities --summary-json，确认当前环境、登录态、组织和可用命令。如果未登录，请引导我完成登录。
```

```
请检查我当前连接的是哪个宜搭环境和组织，并告诉我后续创建应用会发布到哪里。
```

```
请运行 OpenYida 环境诊断，帮我判断 Node.js、登录态、项目目录和命令能力是否正常。
```

## 应用创建

```
帮我创建一个 CRM 宜搭应用。请先理解需求并列出应用结构，再创建应用、表单和必要页面；完成后告诉我应用访问地址和已创建的资源。
```

```
根据下面这份 PRD 生成一个宜搭应用。请先拆解业务对象、页面、表单字段、流程和导航，再使用 OpenYida 创建并发布，最后给我一个可访问链接。

[粘贴 PRD]
```

```
帮我搭建一个项目管理应用，包含项目、任务、里程碑、成员、风险和进度看板。完成后整理应用导航，让首页、业务处理、数据管理和报表入口清晰可见。
```

```
帮我创建一个个人薪资计算器应用，支持税前工资、专项扣除、个税和实发工资计算。请创建表单、公式和一个结果说明页面。
```

## 表单与流程

```
帮我创建一个请假申请表单，包含员工姓名、部门、请假类型、开始日期、结束日期和请假原因；员工姓名、请假类型和日期必填。
```

```
给员工信息表单增加一个部门字段，选项为工程部、市场部、销售部、人事部。请先获取真实表单 Schema，再更新字段。
```

```
帮我创建一个采购审批流程，包含申请人提交、直属主管审批、财务复核和归档。完成后告诉我流程是否已发布。
```

```
把这个表单按业务语义分组，并优化字段说明、必填项和校验规则。修改前请先读取当前 Schema。
```

<Note>
字段 ID 不能从字段名猜测。新增、更新或写入表单数据前，请让 Agent 先读取真实 Schema。
</Note>

## 新版自定义页面

```
把这份分析文档做成宜搭自定义页面。请先理解业务目标和信息层级，生成现代 React 函数组件页面，包含清晰视觉层次、真实交互状态和移动端适配。完成后使用 openyida publish 发布到目标自定义页面，并告诉我页面是否已成功发布。
```

```
帮我创建一个经营看板页面，展示核心指标、趋势图、待办列表和异常提醒。页面需要支持筛选、刷新、空态和错误态，并适配移动端。
```

```
帮我把现有自定义页面改成更适合 B 端使用的工作台：信息密度更高，导航清晰，按钮和筛选都要真实可交互。改完后发布并回读确认。
```

```
帮我创建一个全屏数据大屏页面，隐藏宜搭导航，接入已有表单数据源，发布后告诉我页面地址。
```

## 应用管理

```
帮我整理这个应用的左侧导航：把入口页放在最前，业务处理、数据管理、报表分析和系统配置分组清楚。调整前先列出当前导航结构。
```

```
帮我给这个应用配置多语言：启用中文和英文，整理页面标题、按钮、表单字段和提示文案。完成后告诉我哪些文案已更新。
```

```
帮我查询并调整这个应用的管理员配置：先搜索用户，再把指定成员加入开发成员或数据管理员。修改前请列出当前权限。
```

```
帮我查询当前组织的宜搭基础信息、容量、额度和域名配置，并总结哪些信息会影响应用发布。
```

```
帮我检查这个应用是否启用；如果需要停用或启用，请先说明影响范围并等待我确认。
```

## 数据管理

```
请查询 [表单名] 最近 20 条记录，并按创建时间倒序展示关键字段。
```

```
请先读取 [表单名] 的 Schema，再帮我写入 3 条业务化测试数据。写入后查询一条记录验证字段值是否正确。
```

```
请帮我更新指定记录的状态字段。更新前先确认实例 ID 和字段 ID，更新后查询回读验证。
```

```
请导出 [表单名] 的数据摘要，包含总数、按状态统计和最近更新时间。
```

## 连接器与 API 集成

```
请根据这个 curl 命令智能创建宜搭 HTTP 连接器，识别 Host、路径、请求方法、鉴权方式和参数。创建完成后列出连接器 ID 和动作列表。

[粘贴 curl]
```

```
请给已有连接器添加一个查询动作，并用一组示例参数测试。测试通过后告诉我返回结构。
```

```
请解析这份 API 文档，生成 OpenYida 连接器操作模板，不要直接写入线上连接器，先让我确认。
```

```
请基于 [表单名] 创建一个宜搭原生报表，包含月度提交量柱状图和状态分布饼图。完成后告诉我报表地址。
```

```
请给已有报表追加一个趋势图，展示最近 30 天的记录变化。追加前先确认报表 ID 和数据源字段。
```

```
请创建一个高级可视化看板页面，用表单数据展示指标卡、趋势图和明细表，并发布到自定义页面。
```

## 听记与文档

```
请根据这个钉钉听记 taskUuid 读取会议内容，并整理成 PRD 文档。输出要包含背景、目标、用户故事、功能范围、页面结构和验收标准。

[粘贴 taskUuid]
```

```
请把下面的会议纪要转换成结构化 PRD，并基于 PRD 评估是否可以直接创建宜搭应用。

[粘贴会议纪要]
```

## 分享与发布配置

```
请帮我发布 [页面名]，发布前确认目标 appType、formUuid 和源码路径，发布后告诉我页面是否可访问。
```

```
请帮我配置 [页面名] 的公开访问权限。修改前先说明公开范围和风险，等我确认后再执行。
```

```
请帮我检查这个短链接是否有效，并告诉我它指向哪个应用或页面。
```

---

<Tip>
**写提示词时尽量给足上下文。** 比起“创建一个表单”，更推荐写成：“创建一个请假审批表单，包含员工姓名、部门、请假类型（年假/病假/事假）、起止日期和原因；员工姓名、请假类型和日期必填；创建后配置审批流程并告诉我页面地址。”
</Tip>
