Этот документ описывает Отчеты и графики в OpenYida: сценарии использования, команды и важные замечания.

Следуйте шагам из документа вместе с OpenYida CLI и настройками организации. Если ниже есть примеры кода, их можно скопировать и адаптировать под задачу.

## Команды и примеры

Следующие примеры сохраняют исходные команды и код для технической точности.

```bash
openyida create-report <appType> "Report Name" '<chart-definition-JSON-or-file>'
```

```bash
openyida create-report APP_XXXXXX "Sales Dashboard" '{
  "charts": [
    {
      "type": "bar",
      "title": "Monthly Sales",
      "cubeCode": "FORM_XXXXXX",
      "xField": "month",
      "yField": "amount"
    }
  ]
}'
```

```bash
openyida create-report APP_XXXXXX "Annual Report" ./charts-config.json
```

```bash
openyida append-chart <appType> <reportId> '<chart-definition-JSON-or-file>'
```

```bash

  "type": "line",
```
