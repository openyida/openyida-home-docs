Следуйте шагам из документа вместе с OpenYida CLI и настройками организации. Если ниже есть примеры кода, их можно скопировать и адаптировать под задачу.

## Команды и примеры

Следующие примеры сохраняют исходные команды и код для технической точности.

```bash
openyida doctor
```

```bash
openyida doctor --fix
```

```bash
openyida doctor --report markdown
openyida doctor --report json
openyida doctor --report html
```

```bash
openyida doctor --monitor
```

```bash
openyida doctor env
```

```bash
# Node.js version
openyida doctor env --check node

# Playwright browsers
openyida doctor env --check playwright

# Login status
openyida doctor env --check auth

# Network connectivity
openyida doctor env --check network
```

```bash
openyida doctor app --app <appId>
```

```bash
# Check PRD files
openyida doctor app --check prd

# Check page source
openyida doctor app --check pages

# Check schema cache
openyida doctor app --check schema

# Check React Hooks
openyida doctor app --check hooks
```
