# Menggunakan Codex

Halaman ini menerangkan Menggunakan Codex dalam OpenYida, termasuk tujuan, aliran penggunaan dan perkara penting semasa membina aplikasi Yida dengan AI.

## Gambaran keseluruhan

Dokumen ini menerangkan Menggunakan Codex dalam OpenYida, termasuk aliran penggunaan, arahan dan perkara yang perlu diberi perhatian.

## Perkara penting

- Gunakan halaman ini untuk memahami konteks utama sebelum menggunakannya dalam projek sebenar.
- Nama arahan, parameter, kod dan beberapa nama produk dikekalkan dalam bahasa Inggeris supaya mudah dicari dan disalin dengan tepat.
- Apabila bekerja dengan宜搭, semak kebenaran, organisasi dan persekitaran sebelum penerbitan.

## Penggunaan

Ikuti langkah dalam dokumen ini bersama OpenYida CLI dan konfigurasi organisasi. Jika terdapat contoh kod di bawah, contoh tersebut boleh disalin dan disesuaikan mengikut keperluan.

## Arahan dan contoh

Contoh berikut mengekalkan arahan dan kod asal untuk memastikan ketepatan teknikal.

```bash
    npm install -g openyida
    ```

```
    Help me log in to Yida
    ```

```
@Yida Help me create a project management system
```

```
Build an employee training management system on Yida, including a course schedule, registration form, and assessment scores table
```

```
Help me create a CRM system:
- Lead management: name, company, phone, source, follow-up status
- Customer profiles: linked to leads, industry, annual revenue, account manager
- Opportunity tracking: linked to customer, amount, stage, expected close date
```

```
Add a data analytics dashboard to my app showing this month's total opportunity amount and close rate
```
