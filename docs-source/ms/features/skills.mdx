# Rujukan CLI

Halaman ini menerangkan Rujukan CLI dalam OpenYida, termasuk tujuan, aliran penggunaan dan perkara penting semasa membina aplikasi Yida dengan AI.

## Gambaran keseluruhan

Dokumen ini menerangkan Rujukan CLI dalam OpenYida, termasuk aliran penggunaan, arahan dan perkara yang perlu diberi perhatian.

## Perkara penting

- Gunakan halaman ini untuk memahami konteks utama sebelum menggunakannya dalam projek sebenar.
- Nama arahan, parameter, kod dan beberapa nama produk dikekalkan dalam bahasa Inggeris supaya mudah dicari dan disalin dengan tepat.
- Apabila bekerja dengan宜搭, semak kebenaran, organisasi dan persekitaran sebelum penerbitan.

## Penggunaan

Ikuti langkah dalam dokumen ini bersama OpenYida CLI dan konfigurasi organisasi. Jika terdapat contoh kod di bawah, contoh tersebut boleh disalin dan disesuaikan mengikut keperluan.

## Arahan dan contoh

Contoh berikut mengekalkan arahan dan kod asal untuk memastikan ketepatan teknikal.

```bash
# Environment check
openyida env
openyida env --json

# Multi-environment management
openyida env setup                 # Configure public, overseas, intranet, or private deployment presets
openyida env list                  # List all environments, highlight the active one
openyida env add <name>            # Interactively add a private deployment environment
openyida env switch <name>         # Switch the active environment
openyida env remove <name>         # Remove an environment (cannot remove "public")
openyida env show [name]           # Show detailed environment configuration

# Login
openyida login [--qr|--agent-qr|--codex|--browser] [--env <name>|--intl|--overseas|--global|--yidaapps] [--corp-id <corpId>]
openyida login --check-only --json # Check the current login state only

# Logout
openyida logout

# Auth management
openyida auth status               # Check login status
openyida auth login                # Perform login
openyida auth refresh              # Refresh session
openyida auth logout               # Logout

# Organization management
openyida org list                  # List accessible organizations
openyida org switch --corp-id <id> # Switch organization

# Initialize workspace
openyida copy [--force]            # Copy project directory (flattens into empty dirs)
openyida copy -skills              # Copy yida-skills to AI tool skills directory

# Diagnostic tools
openyida doctor [--fix]            # Environment diagnosis
openyida doctor --monitor          # Health monitoring
openyida doctor --report <format>  # Generate report (json|markdown|html)

# Self-update
openyida update                    # Check for and install the latest version

# Machine-readable command manifest
openyida commands --json           # Print the current CLI manifest
```

```bash
# List applications
openyida app-list [--size N]

# Create application
openyida create-app "<name>" [desc] [icon] [color] [themeColor] [--locale zh_CN|en_US|ja_JP] [--open|--no-open]
openyida create-app --name "<name>" [--desc "<description>"] [--theme deepBlue] [--locale zh_CN|en_US|ja_JP] [--open|--no-open]

# Export application
openyida export <appType> [output] # Generate migration package

# Import application
openyida import <file> [name]      # Rebuild app from migration package

# Update application info
openyida update-app <appType> --name "<name>" [--desc "<description>"] [--icon "<icon>"] [--icon-color "<color>"]

# Manage application-level permissions
openyida app-permission <get|set|add|remove|search-user> ...

# Navigation groups and app i18n
openyida nav-group <list|create|rename|delete|move|hide|show> <appType> ...
openyida i18n <overview|config|languages|list|upsert|batch-upsert|bind|delete|translate|translate-all|upgrade> <appType> ...
```

# Create form
openyida create-form create <appType> "<form name>" <fieldsJSON> \
  [--layout <layout>] \
  [--theme <theme>] \
  [--label-align <alignment>] \
  [--locale zh_CN|en_US|ja_JP]

# Update form
openyida create-form update <appType> <formUuid> <changesJsonOrFile> [--force] [--locale zh_CN|en_US|ja_JP] [--open|--no-open]

# Advanced schema patching, field rules, and remote option data sources
openyida create-form patch <appType> <formUuid> <patchJsonOrFile> [--open|--no-open]
openyida create-form rule <appType> <formUuid> <rulesJsonOrFile> [--open|--no-open]
openyida create-form bind-datasource <appType> <formUuid> <fieldLabelOrId> <dataSourceJsonOrFile> [--open|--no-open]

# Add options to a SelectField, RadioField, CheckboxField, or MultiSelectField
openyida create-form add-option <appType> <formUuid> <fieldLabel> <option1> [option2] ...

# Get form schema (required before any field ID operation)
openyida get-schema <appType> <formUuid>
openyida get-schema <appType> --all [--output-dir <dir>]
openyida get-schema <appType> <formUuid> --field <labelOrFieldId> [--json]

# Update form config
openyida update-form-config <appType> <formUuid> <isRenderNav> <title>

# List form pages in an application
openyida list-forms <appType> [--keyword <text>]
