# Perkongsian dan navigasi

Halaman ini menerangkan Perkongsian dan navigasi dalam OpenYida, termasuk tujuan, aliran penggunaan dan perkara penting semasa membina aplikasi Yida dengan AI.

## Gambaran keseluruhan

Dokumen ini menerangkan Perkongsian dan navigasi dalam OpenYida, termasuk aliran penggunaan, arahan dan perkara yang perlu diberi perhatian.

## Perkara penting

- Gunakan halaman ini untuk memahami konteks utama sebelum menggunakannya dalam projek sebenar.
- Nama arahan, parameter, kod dan beberapa nama produk dikekalkan dalam bahasa Inggeris supaya mudah dicari dan disalin dengan tepat.
- Apabila bekerja dengan宜搭, semak kebenaran, organisasi dan persekitaran sebelum penerbitan.

## Penggunaan

Ikuti langkah dalam dokumen ini bersama OpenYida CLI dan konfigurasi organisasi. Jika terdapat contoh kod di bawah, contoh tersebut boleh disalin dan disesuaikan mengikut keperluan.

## Arahan dan contoh

Contoh berikut mengekalkan arahan dan kod asal untuk memastikan ketepatan teknikal.

```bash
openyida verify-short-url <appType> <formUuid> /s/my-dashboard
openyida save-share-config <appType> <formUuid> /s/my-dashboard y
openyida get-page-config <appType> <formUuid>
```

```bash
openyida verify-short-url <appType> <formUuid> /o/my-public-page
openyida save-share-config <appType> <formUuid> /o/my-public-page y n
```

```bash
openyida save-share-config <appType> <formUuid> "" n
```

```bash
openyida update-form-config <appType> <formUuid> false "Page Title"
openyida update-form-config <appType> <formUuid> true "Page Title"
```
