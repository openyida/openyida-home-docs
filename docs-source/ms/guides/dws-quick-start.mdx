# Panduan mula pantas DingTalk CLI

Halaman ini menerangkan Panduan mula pantas DingTalk CLI dalam OpenYida, termasuk tujuan, aliran penggunaan dan perkara penting semasa membina aplikasi Yida dengan AI.

## Gambaran keseluruhan

Dokumen ini menerangkan Panduan mula pantas DingTalk CLI dalam OpenYida, termasuk aliran penggunaan, arahan dan perkara yang perlu diberi perhatian.

## Perkara penting

- Gunakan halaman ini untuk memahami konteks utama sebelum menggunakannya dalam projek sebenar.
- Nama arahan, parameter, kod dan beberapa nama produk dikekalkan dalam bahasa Inggeris supaya mudah dicari dan disalin dengan tepat.
- Apabila bekerja dengan宜搭, semak kebenaran, organisasi dan persekitaran sebelum penerbitan.

## Penggunaan

Ikuti langkah dalam dokumen ini bersama OpenYida CLI dan konfigurasi organisasi. Jika terdapat contoh kod di bawah, contoh tersebut boleh disalin dan disesuaikan mengikut keperluan.

## Arahan dan contoh

Contoh berikut mengekalkan arahan dan kod asal untuk memastikan ketepatan teknikal.

```bash
    openyida dws install
    ```

```bash
    curl -fsSL https://raw.githubusercontent.com/DingTalk-Real-AI/dingtalk-workspace-cli/main/scripts/install.sh | sh
    ```

```bash
        export DWS_CLIENT_ID="your-client-id"
        export DWS_CLIENT_SECRET="your-client-secret"
        ```

```bash
        openyida dws auth login --client-id your-client-id --client-secret your-client-secret
        ```

```bash
    openyida dws auth login
    ```

```bash
# Basic search
openyida dws contact user search --keyword "张三"

# JSON output (suitable for AI Agents)
openyida dws contact user search --keyword "张三" -f json

# Save to file
openyida dws contact user search --keyword "张三" -o contacts.json
```

```bash
# Create a personal to-do
openyida dws todo task create --title "准备周报" --executors "your-userid"

# Create a team to-do
openyida dws todo task create --title "项目评审" --executors "userid1,userid2,userid3"

# List all to-dos
openyida dws todo task list
```

```bash
# Query today's check-in records
openyida dws attendance record list

# Query a specific user's attendance
openyida dws attendance record list --userids "your-userid"
```
