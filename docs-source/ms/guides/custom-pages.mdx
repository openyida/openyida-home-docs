Halaman paparan tersuai sesuai untuk dashboard, portal, laporan visual, kalkulator dan halaman interaktif. OpenYida mengompil React function component moden kepada halaman yang boleh berjalan dalam Yida dan menerbitkannya ke container halaman sasaran.

## Aliran hujung ke hujung

```bash
openyida agent-capabilities --summary-json
openyida create-page <appType> "Dashboard operasi"
# Jana atau tulis sumber halaman: project/pages/src/dashboard.canvas.jsx
openyida publish project/pages/src/dashboard.canvas.jsx <appType> <formUuid>
```

Gunakan `agent-capabilities` untuk menyemak persekitaran, status log masuk dan keupayaan tersedia. `create-page` mengembalikan `formUuid` halaman; jangan teka, baca daripada output arahan atau cache projek. Apabila source siap, gunakan `publish` untuk menerbitkan ke halaman sasaran.

## Peraturan halaman

Halaman baharu patut menggunakan aliran halaman moden, dan source perlu mematuhi peraturan berikut:

- Gunakan React function component sebagai entry halaman.
- Hooks seperti `useState`, `useEffect` dan `useMemo` disokong; bersihkan side effect.
- `import` UI library, chart library dan icon daripada resource yang disokong.
- Button, filter, search, Tabs, pagination dan card mesti memacu interaksi sebenar.
- Utamakan data sebenar melalui Yida data bridge, connector atau Open API; sediakan empty, error dan refresh state.
- Layout mobile mesti mudah dibaca dan kawasan operasi tidak melimpah.

## Komponen native Yida yang disokong

Halaman tersuai boleh bridge komponen runtime native Yida. Kesan dahulu daripada `window.Deep`, `window.DeepYida` atau `window.YidaNativeComponents`; jika gagal, render fallback halaman supaya tidak blank.

| Komponen / senario | Kegunaan | Keperluan integrasi |
| --- | --- | --- |
| `PortalTopBanner` / `PortalQuickEntry` | Banner portal dan pintasan | Utamakan untuk portal shell; jika tiada, gunakan banner dan kad pintasan fallback. |
| `QuickAccessCard` / `RecentlyUsedCard` | Kad aplikasi kerap digunakan dan terbaru | Wajib hantar `theme`, seperti `row-white` atau `column`, serta kekalkan fallback setempat. |
| `DataManageViews` | Benamkan paparan pengurusan data Yida | Hantar `form.appType` dan `form.value` / `formUuid` borang sasaran. |
| `EmployeeField` | Pemilih ahli | Rekod output `onChange` sebenar dahulu, kemudian normalkan nilai ahli. |
| `DepartmentSelectField` | Pemilih jabatan | Sahkan carian, popover, kebenaran, pilihan tunggal dan berbilang. |
| `AttachmentField` / `ImageField` | Muat naik lampiran dan imej | Sahkan kebenaran muat naik, tandatangan OSS, pratonton, padam dan keadaan gagal. |
| `DataCard` / `PortalContainer` | Kad data portal dan container | Gunakan hanya selepas konteks portal, konfigurasi data dan pemboleh ubah gaya disahkan. |

Komponen native ialah peningkatan pengalaman, bukan prasyarat kestabilan halaman. Kekalkan fallback dan normalkan ahli, jabatan serta fail sebelum submit.

## Contoh boleh disalin

```bash
openyida sample yida-canvas-custom-page native-components-smoke --output project/pages/src/native-components-smoke.canvas.jsx
openyida sample yida-canvas-custom-page portal-native-components --output project/pages/src/portal-native-components.canvas.jsx
openyida build-page project/pages/src/native-components-smoke.canvas.jsx --write
```

## Terbitkan dan sahkan

```bash
openyida publish project/pages/src/dashboard.canvas.jsx <appType> <formUuid>
```

Sebelum terbit, pastikan source mempunyai interaksi sebenar, responsif mobile, empty/error state dan logik data yang diperlukan. `publish` mengemas kini source semasa ke halaman sasaran daripada `create-page`.

## Sembunyikan navigasi Yida

Dashboard skrin penuh atau halaman demo boleh menyembunyikan navigasi platform:

```bash
openyida update-form-config <appType> <formUuid> false "Dashboard operasi"
```

Paparkan navigasi semula:

```bash
openyida update-form-config <appType> <formUuid> true "Dashboard operasi"
```

## Bila menggunakan `build-page`

```bash
openyida build-page project/pages/src/dashboard.canvas.jsx --write
```

`build-page` hanya memproses source tempatan dan tidak menerbitkan. Sesuai untuk review, CI atau debug output compile.
