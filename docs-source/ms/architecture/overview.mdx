# Gambaran keseluruhan seni bina

Halaman ini menerangkan Gambaran keseluruhan seni bina dalam OpenYida, termasuk tujuan, aliran penggunaan dan perkara penting semasa membina aplikasi Yida dengan AI.

## Gambaran keseluruhan

Dokumen ini menerangkan Gambaran keseluruhan seni bina dalam OpenYida, termasuk aliran penggunaan, arahan dan perkara yang perlu diberi perhatian.

## Perkara penting

- Gunakan halaman ini untuk memahami konteks utama sebelum menggunakannya dalam projek sebenar.
- Nama arahan, parameter, kod dan beberapa nama produk dikekalkan dalam bahasa Inggeris supaya mudah dicari dan disalin dengan tepat.
- Apabila bekerja dengan宜搭, semak kebenaran, organisasi dan persekitaran sebelum penerbitan.

## Penggunaan

Ikuti langkah dalam dokumen ini bersama OpenYida CLI dan konfigurasi organisasi. Jika terdapat contoh kod di bawah, contoh tersebut boleh disalin dan disesuaikan mengikut keperluan.

## Arahan dan contoh

Contoh berikut mengekalkan arahan dan kod asal untuk memastikan ketepatan teknikal.

```
AI coding agent
  -> openyida CLI
  -> local project workspace
  -> Yida web APIs with cached login cookies
  -> Yida low-code app, form, page, report, or data result
```

```text
project/
  config.json
  pages/
    src/
    build/
    dist/
  .cache/
```

```bash
openyida create-page <appType> "Dashboard"
openyida check-page project/pages/src/dashboard.oyd.jsx
openyida compile project/pages/src/dashboard.oyd.jsx
openyida publish project/pages/src/dashboard.oyd.jsx <appType> <formUuid>
```

```bash
openyida env --json
openyida login --check-only --json
openyida env <setup|list|show|switch|add|remove>
```

```bash
openyida get-schema <appType> <formUuid>
```

```bash
openyida commands --json
```
