## When to use

Application management covers organization, permissions, navigation, i18n, and lifecycle management after an app has been created. It makes generated apps usable, maintainable, and deliverable.

## Capabilities

- Navigation groups: use `openyida nav-group` to organize side navigation.
- Internationalization: use `openyida i18n` for page titles, buttons, fields, and messages.
- App permissions: use `openyida app-permission` to query and adjust administrators, developers, or data admins.
- Lifecycle: use `openyida app-online` and `openyida app-offline`.
- Basics: use `openyida basic-info` and `openyida corp-manager` for organization and platform settings.

## Prompt example

```
Organize this app's left navigation: put the entry page first, then group business operations, data management, reports, and system settings. List the current navigation structure before changing it.
```

## AI Agent Prompt Template

```
Manage this Yida app. First inspect the current navigation, i18n, permissions, lifecycle state, and organization basics. Then propose the exact changes and affected objects. Only apply permission, lifecycle, or public-access changes after confirming the impact scope.

Target app: [app name or appType]
Management task: [describe task]
```

## Acceptance Checklist

- Current state is listed before changes.
- Permission and lifecycle changes include impact scope.
- Navigation and i18n updates are read back after execution.
- The final result includes changed objects and follow-up risks.
