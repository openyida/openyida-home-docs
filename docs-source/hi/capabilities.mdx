यह सूची Yida users और AI Agents के लिए OpenYida की मौजूदा क्षमताओं और आम तौर पर उपयोग किए जाने वाले `openyida` commands को scenario के अनुसार सारांशित करती है।

<Note>
Default lightweight preflight के लिए `openyida agent-capabilities --summary-json` इस्तेमाल करें। Full diagnostics, command Manifest, permission metadata या raw login failure details की जरूरत हो तभी `openyida agent-capabilities --json` इस्तेमाल करें।
</Note>

## Basics

| क्षमता | Command |
|---|---|
| Lightweight agent preflight | `openyida agent-capabilities --summary-json` |
| Full agent diagnostics | `openyida agent-capabilities --json` |
| Environment और login check | `openyida env` / `openyida env --json` |
| Environment profile management | `openyida env <setup\|list\|show\|switch\|add\|remove>` |
| OAuth token login | `openyida login` |
| Target URL login | `openyida login <target-url>` |
| Token status और refresh | `openyida auth <status\|login\|refresh\|logout>` |
| Organization switch | `openyida org <list\|switch> [--corp-id <corpId>]` |
| Command Manifest | `openyida commands --json` |

## Apps और Forms

| क्षमता | Command |
|---|---|
| Apps list करना | `openyida app-list [--size N]` |
| Apps create/update करना | `openyida create-app ...` / `openyida update-app ...` |
| Migration packages import/export करना | `openyida export ...` / `openyida import ...` |
| Forms create, update, patch, validate या bind करना | `openyida create-form <create\|update\|patch\|rule\|validation\|bind-datasource> ...` |
| Forms और Schemas query करना | `openyida list-forms ...` / `openyida get-schema ...` |
| App navigation groups manage करना | `openyida nav-group <list\|create\|rename\|delete\|move\|order\|hide\|show> ...` |
| Permissions manage करना | `openyida app-permission ...` / `openyida get-permission ...` / `openyida save-permission ...` |

## Pages, Data और Process

| क्षमता | Command |
|---|---|
| Display pages create करना | `openyida create-page <appType> "<name>"` |
| Page code generate, check, compile और publish करना | `openyida generate-page ...` / `openyida check-page ...` / `openyida compile ...` / `openyida publish ...` |
| Code Canvas pages publish करना | `openyida publish <src.canvas.jsx> <appType> <formUuid>` |
| Form/process/task/subform data query या mutate करना | `openyida data <action> <resource> ...` |
| Process forms create और configure करना | `openyida create-process ...` / `openyida configure-process ...` |
| Tasks और delegation query करना | `openyida task-center ...` / `openyida agent-center ...` |

## Integration, Reports और Utilities

| क्षमता | Command |
|---|---|
| Reports और dashboards | `openyida create-report ...` / `openyida append-chart ...` |
| HTTP connectors | `openyida connector <list\|create\|detail\|add-action\|test\|smart-create> ...` |
| Integration automation | `openyida integration <create\|list\|enable\|disable\|check\|diagnose> ...` |
| DingTalk documents और DWS CLI | `openyida read-dingtalk-doc ...` / `openyida dws <command>` |
| AI, assets, formulas और PRD conversion | `openyida ai ...` / `openyida asset ...` / `openyida formula evaluate ...` / `openyida flash-to-prd ...` |
| Local setup, diagnostics और batch | `openyida copy` / `openyida doctor` / `openyida batch` |
| MCP, A2A और local bridge | `openyida mcp` / `openyida a2a ...` / `openyida bridge start ...` |
| Quiet output और update checks | `openyida --quiet ...` / `YIDA_QUIET=1` / `OPENYIDA_SKIP_UPDATE_CHECK=1` |

## कस्टम पेज, प्रकाशन श्रृंखला और i18n

| क्षमता | कमांड |
|---|---|
| पेज स्पेक से बिजनेस Code Canvas पेज जनरेट करें | `openyida generate-page <template> --spec <page-spec.json> --output project/pages/src/<name>.canvas.jsx --compile` |
| जनरेशन के दौरान थीम प्रोफाइल और स्कोप लागू करें | `openyida generate-page ... --theme-profile <profile> --theme-scope <page\|global>` |
| Code Canvas सैंपल पेज बनाएं | `openyida sample yida-canvas-custom-page <sample> --output project/pages/src/<name>.canvas.jsx` |
| क्लासिक कस्टम पेज सैंपल बनाएं | `openyida sample yida-custom-page <sample> --output project/pages/src/<name>.oyd.jsx` |
| प्रकाशित करने से पहले पेज कोड जांचें और सामान्य करें | `openyida check-page <src>` / `openyida build-page <src> --write` |
| डिजाइनर बदलावों को overwrite करने से पहले लाइव कॉन्फिग पढ़ें | `openyida get-form-config <appType> <formUuid> --json` / `openyida get-schema <appType> <formUuid>` |
| क्लासिक कस्टम पेज प्रकाशित करें | `openyida publish project/pages/src/<name>.oyd.jsx <appType> <formUuid>` |
| Code Canvas पेज प्रकाशित करें | `openyida publish project/pages/src/<name>.canvas.jsx <appType> <formUuid> --canvas` |
| प्रकाशित करने के तुरंत बाद health check चलाएं | `openyida publish <src> <appType> <formUuid> --health-check` |
| प्रकाशित करने के बाद पेज या फॉर्म कॉन्फिग अपडेट करें | `openyida update-form-config <appType> <formUuid> ...` |
| सार्वजनिक एक्सेस, छिपा हुआ नेविगेशन और शेयर एंट्री कॉन्फिग करें | `openyida verify-short-url ...` / `openyida save-share-config ...` / `openyida get-page-config ...` |
| पेज assets को CDN पर अपलोड करें | `openyida cdn-upload <asset-path>` |
| CDN कॉन्फिग पढ़ें और संसाधन refresh करें | `openyida cdn-config` / `openyida cdn-refresh ...` |
| OpenYida CLI पैकेज जांचें और अपग्रेड करें | `openyida update` / `npm install -g openyida@latest` |
| ऐप भाषा पैक प्रबंधित करें | `openyida i18n <overview\|config\|languages\|list\|upsert\|batch-upsert\|bind\|delete\|translate\|translate-all\|upgrade> ...` |
| चुने हुए भाषा पैक के साथ CLI चलाएं | `OPENYIDA_LANG=<locale> openyida ...` / `OPENYIDA_LOCALE_DIR=<dir> openyida ...` |

<Warning>
पुराने login flags जैसे `--qr`, `--browser`, `--codex`, `--qoder` अब supported नहीं हैं। OAuth token login का उपयोग करें।
</Warning>
