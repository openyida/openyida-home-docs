# คำถามที่พบบ่อย

หน้านี้อธิบาย คำถามที่พบบ่อย ของ OpenYida โดยสรุปเป้าหมาย ขั้นตอนการใช้งาน และข้อควรระวังที่เกี่ยวข้องสำหรับการสร้างแอป Yida ด้วย AI

## ภาพรวม

เอกสารนี้อธิบาย คำถามที่พบบ่อย ใน OpenYida พร้อมแนวทางการใช้งาน คำสั่ง และข้อควรทราบที่เกี่ยวข้อง

## ประเด็นสำคัญ

- ใช้หน้านี้เพื่อทำความเข้าใจบริบทหลักก่อนเริ่มลงมือในโครงการจริง
- ชื่อคำสั่ง พารามิเตอร์ โค้ด และชื่อผลิตภัณฑ์บางส่วนคงไว้เป็นภาษาอังกฤษเพื่อให้ค้นหาและคัดลอกได้ถูกต้อง
- เมื่อใช้งานกับ宜搭จริง ให้ตรวจสอบสิทธิ์ องค์กร และสภาพแวดล้อมก่อนเผยแพร่

## การใช้งาน

ปฏิบัติตามขั้นตอนในเอกสารนี้ร่วมกับคำสั่ง OpenYida CLI และการตั้งค่าขององค์กร หากมีตัวอย่างโค้ดด้านล่าง สามารถคัดลอกไปปรับใช้ได้โดยตรง

## คำสั่งและตัวอย่าง

ตัวอย่างต่อไปนี้คงคำสั่งและโค้ดต้นฉบับไว้เพื่อความถูกต้องทางเทคนิค

```bash
    openyida org list       # List all organizations and corpIds
    openyida org switch --corp-id <corpId>   # Switch to target organization
    openyida env            # Confirm the switch
    ```

```
    Add a [field name] field to [page name], field type: [TextField/NumberField/DateField/SelectField/...], make it required
    ```

```
    Make [page name] page publicly accessible
    ```

```bash
    openyida verify-short-url <appType> <formUuid> /o/my-public-page
    openyida save-share-config <appType> <formUuid> /o/my-public-page y n
    ```

```bash
    openyida verify-short-url <appType> <formUuid> /s/my-dashboard
    openyida save-share-config <appType> <formUuid> /s/my-dashboard y
    openyida get-page-config <appType> <formUuid>
    ```

```bash
    openyida update-form-config <appType> <formUuid> false "Page Title"
    ```

```bash
    openyida update-form-config <appType> <formUuid> true "Page Title"
    ```
