# คู่มือเริ่มต้น DingTalk CLI

หน้านี้อธิบาย คู่มือเริ่มต้น DingTalk CLI ของ OpenYida โดยสรุปเป้าหมาย ขั้นตอนการใช้งาน และข้อควรระวังที่เกี่ยวข้องสำหรับการสร้างแอป Yida ด้วย AI

## ภาพรวม

เอกสารนี้อธิบาย คู่มือเริ่มต้น DingTalk CLI ใน OpenYida พร้อมแนวทางการใช้งาน คำสั่ง และข้อควรทราบที่เกี่ยวข้อง

## ประเด็นสำคัญ

- ใช้หน้านี้เพื่อทำความเข้าใจบริบทหลักก่อนเริ่มลงมือในโครงการจริง
- ชื่อคำสั่ง พารามิเตอร์ โค้ด และชื่อผลิตภัณฑ์บางส่วนคงไว้เป็นภาษาอังกฤษเพื่อให้ค้นหาและคัดลอกได้ถูกต้อง
- เมื่อใช้งานกับ宜搭จริง ให้ตรวจสอบสิทธิ์ องค์กร และสภาพแวดล้อมก่อนเผยแพร่

## การใช้งาน

ปฏิบัติตามขั้นตอนในเอกสารนี้ร่วมกับคำสั่ง OpenYida CLI และการตั้งค่าขององค์กร หากมีตัวอย่างโค้ดด้านล่าง สามารถคัดลอกไปปรับใช้ได้โดยตรง

## คำสั่งและตัวอย่าง

ตัวอย่างต่อไปนี้คงคำสั่งและโค้ดต้นฉบับไว้เพื่อความถูกต้องทางเทคนิค

```bash
    openyida dws install
    ```

```bash
    curl -fsSL https://raw.githubusercontent.com/DingTalk-Real-AI/dingtalk-workspace-cli/main/scripts/install.sh | sh
    ```

```bash
        export DWS_CLIENT_ID="your-client-id"
        export DWS_CLIENT_SECRET="your-client-secret"
        ```

```bash
        openyida dws auth login --client-id your-client-id --client-secret your-client-secret
        ```

```bash
    openyida dws auth login
    ```

```bash
# Basic search
openyida dws contact user search --keyword "张三"

# JSON output (suitable for AI Agents)
openyida dws contact user search --keyword "张三" -f json

# Save to file
openyida dws contact user search --keyword "张三" -o contacts.json
```

```bash
# Create a personal to-do
openyida dws todo task create --title "准备周报" --executors "your-userid"

# Create a team to-do
openyida dws todo task create --title "项目评审" --executors "userid1,userid2,userid3"

# List all to-dos
openyida dws todo task list
```

```bash
# Query today's check-in records
openyida dws attendance record list

# Query a specific user's attendance
openyida dws attendance record list --userids "your-userid"
```
