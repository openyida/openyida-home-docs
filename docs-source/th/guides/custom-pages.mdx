# หน้ากำหนดเอง

หน้านี้อธิบาย หน้ากำหนดเอง ของ OpenYida โดยสรุปเป้าหมาย ขั้นตอนการใช้งาน และข้อควรระวังที่เกี่ยวข้องสำหรับการสร้างแอป Yida ด้วย AI

## ภาพรวม

เอกสารนี้อธิบาย หน้ากำหนดเอง ใน OpenYida พร้อมแนวทางการใช้งาน คำสั่ง และข้อควรทราบที่เกี่ยวข้อง

## ประเด็นสำคัญ

- ใช้หน้านี้เพื่อทำความเข้าใจบริบทหลักก่อนเริ่มลงมือในโครงการจริง
- ชื่อคำสั่ง พารามิเตอร์ โค้ด และชื่อผลิตภัณฑ์บางส่วนคงไว้เป็นภาษาอังกฤษเพื่อให้ค้นหาและคัดลอกได้ถูกต้อง
- เมื่อใช้งานกับ宜搭จริง ให้ตรวจสอบสิทธิ์ องค์กร และสภาพแวดล้อมก่อนเผยแพร่

## การใช้งาน

ปฏิบัติตามขั้นตอนในเอกสารนี้ร่วมกับคำสั่ง OpenYida CLI และการตั้งค่าขององค์กร หากมีตัวอย่างโค้ดด้านล่าง สามารถคัดลอกไปปรับใช้ได้โดยตรง

## คำสั่งและตัวอย่าง

ตัวอย่างต่อไปนี้คงคำสั่งและโค้ดต้นฉบับไว้เพื่อความถูกต้องทางเทคนิค

```bash
openyida create-page <appType> "Dashboard"
openyida check-page project/pages/src/dashboard.oyd.jsx
openyida compile project/pages/src/dashboard.oyd.jsx
openyida publish project/pages/src/dashboard.oyd.jsx <appType> <formUuid>
```

```bash
openyida check-page project/pages/src/dashboard.oyd.jsx
openyida compile project/pages/src/dashboard.oyd.jsx
```

```bash
openyida update-form-config <appType> <formUuid> false "Dashboard"
```

```bash
openyida update-form-config <appType> <formUuid> true "Dashboard"
```

```bash
openyida build-page project/pages/src/dashboard.oyd.jsx --write
```
