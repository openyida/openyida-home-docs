# ตัวเชื่อมต่อ (การผสาน HTTP)

หน้านี้อธิบาย ตัวเชื่อมต่อ (การผสาน HTTP) ของ OpenYida โดยสรุปเป้าหมาย ขั้นตอนการใช้งาน และข้อควรระวังที่เกี่ยวข้องสำหรับการสร้างแอป Yida ด้วย AI

## ภาพรวม

เอกสารนี้อธิบาย ตัวเชื่อมต่อ (การผสาน HTTP) ใน OpenYida พร้อมแนวทางการใช้งาน คำสั่ง และข้อควรทราบที่เกี่ยวข้อง

## ประเด็นสำคัญ

- ใช้หน้านี้เพื่อทำความเข้าใจบริบทหลักก่อนเริ่มลงมือในโครงการจริง
- ชื่อคำสั่ง พารามิเตอร์ โค้ด และชื่อผลิตภัณฑ์บางส่วนคงไว้เป็นภาษาอังกฤษเพื่อให้ค้นหาและคัดลอกได้ถูกต้อง
- เมื่อใช้งานกับ宜搭จริง ให้ตรวจสอบสิทธิ์ องค์กร และสภาพแวดล้อมก่อนเผยแพร่

## การใช้งาน

ปฏิบัติตามขั้นตอนในเอกสารนี้ร่วมกับคำสั่ง OpenYida CLI และการตั้งค่าขององค์กร หากมีตัวอย่างโค้ดด้านล่าง สามารถคัดลอกไปปรับใช้ได้โดยตรง

## คำสั่งและตัวอย่าง

ตัวอย่างต่อไปนี้คงคำสั่งและโค้ดต้นฉบับไว้เพื่อความถูกต้องทางเทคนิค

```bash
openyida connector smart-create \
  --curl "curl 'https://api.example.com/v1/users' -H 'Authorization: Bearer xxx'" \
  --name "User Management Connector" \
  --desc "HTTP connector for managing user data"
```

```bash
# List all connectors
openyida connector list

# Filter by keyword
openyida connector list --keyword "user"

# Filter by type (mine or manager)
openyida connector list --type mine

# Filter by date range
openyida connector list --start-date 2024-01-01 --end-date 2024-12-31

# Set page size
openyida connector list --page-size 50
```

```bash
openyida connector create "Connector Name" "api.example.com" \
  --operations ./operations.json \
  --desc "Connector description"
```

```bash
openyida connector detail <connector-id>
```

```bash
openyida connector delete <connector-id> --force
```

```bash
openyida connector add-action \
  --connector-id <id> \
  --operations ./new-action.json \
  --confirm
```

```bash
openyida connector list-actions <connector-id>
```

```bash
openyida connector test \
  --connector-id <id> \
  --action <actionId> \
  --params '{"key": "value"}'
```
