# Tanılama araçları

Bu sayfa OpenYida içinde Tanılama araçları konusunu açıklar; amaç, kullanım akışı ve AI ile Yida uygulaması geliştirirken dikkat edilmesi gereken noktaları kapsar.

## Genel bakış

Bu belge OpenYida içinde Tanılama araçları konusunu; kullanım akışı, komutlar ve dikkat edilmesi gereken noktalarla açıklar.

## Önemli noktalar

- Gerçek bir projeye uygulamadan önce ana bağlamı anlamak için bu sayfayı kullanın.
- Komut adları, parametreler, kod ve bazı ürün adları doğru arama ve kopyalama için İngilizce bırakılmıştır.
- 宜搭 ile çalışırken yayımlamadan önce izinleri, organizasyonu ve ortamı kontrol edin.

## Kullanım

Bu dokümandaki adımları OpenYida CLI ve organizasyon ayarlarıyla birlikte izleyin. Aşağıdaki kod örnekleri doğrudan kopyalanıp ihtiyaca göre uyarlanabilir.

## Komutlar ve örnekler

Aşağıdaki örnekler teknik doğruluğu korumak için özgün komut ve kodu saklar.

```bash
openyida doctor
```

```bash
openyida doctor --fix
```

```bash
openyida doctor --report markdown
openyida doctor --report json
openyida doctor --report html
```

```bash
openyida doctor --monitor
```

```bash
openyida doctor env
```

```bash
# Node.js version
openyida doctor env --check node

# Playwright browsers
openyida doctor env --check playwright

# Login status
openyida doctor env --check auth

# Network connectivity
openyida doctor env --check network
```

```bash
openyida doctor app --app <appId>
```

```bash
# Check PRD files
openyida doctor app --check prd

# Check page source
openyida doctor app --check pages

# Check schema cache
openyida doctor app --check schema

# Check React Hooks
openyida doctor app --check hooks
```
