# Özel sayfalar

Bu sayfa OpenYida içinde Özel sayfalar konusunu açıklar; amaç, kullanım akışı ve AI ile Yida uygulaması geliştirirken dikkat edilmesi gereken noktaları kapsar.

## Genel bakış

Bu belge OpenYida içinde Özel sayfalar konusunu; kullanım akışı, komutlar ve dikkat edilmesi gereken noktalarla açıklar.

## Önemli noktalar

- Gerçek bir projeye uygulamadan önce ana bağlamı anlamak için bu sayfayı kullanın.
- Komut adları, parametreler, kod ve bazı ürün adları doğru arama ve kopyalama için İngilizce bırakılmıştır.
- 宜搭 ile çalışırken yayımlamadan önce izinleri, organizasyonu ve ortamı kontrol edin.

## Kullanım

Bu dokümandaki adımları OpenYida CLI ve organizasyon ayarlarıyla birlikte izleyin. Aşağıdaki kod örnekleri doğrudan kopyalanıp ihtiyaca göre uyarlanabilir.

## Komutlar ve örnekler

Aşağıdaki örnekler teknik doğruluğu korumak için özgün komut ve kodu saklar.

```bash
openyida create-page <appType> "Dashboard"
openyida check-page project/pages/src/dashboard.oyd.jsx
openyida compile project/pages/src/dashboard.oyd.jsx
openyida publish project/pages/src/dashboard.oyd.jsx <appType> <formUuid>
```

```bash
openyida check-page project/pages/src/dashboard.oyd.jsx
openyida compile project/pages/src/dashboard.oyd.jsx
```

```bash
openyida update-form-config <appType> <formUuid> false "Dashboard"
```

```bash
openyida update-form-config <appType> <formUuid> true "Dashboard"
```

```bash
openyida build-page project/pages/src/dashboard.oyd.jsx --write
```
