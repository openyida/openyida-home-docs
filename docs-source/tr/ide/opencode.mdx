# OpenCode kullanımı

Bu sayfa OpenYida içinde OpenCode kullanımı konusunu açıklar; amaç, kullanım akışı ve AI ile Yida uygulaması geliştirirken dikkat edilmesi gereken noktaları kapsar.

## Genel bakış

Bu belge OpenYida içinde OpenCode kullanımı konusunu; kullanım akışı, komutlar ve dikkat edilmesi gereken noktalarla açıklar.

## Önemli noktalar

- Gerçek bir projeye uygulamadan önce ana bağlamı anlamak için bu sayfayı kullanın.
- Komut adları, parametreler, kod ve bazı ürün adları doğru arama ve kopyalama için İngilizce bırakılmıştır.
- 宜搭 ile çalışırken yayımlamadan önce izinleri, organizasyonu ve ortamı kontrol edin.

## Kullanım

Bu dokümandaki adımları OpenYida CLI ve organizasyon ayarlarıyla birlikte izleyin. Aşağıdaki kod örnekleri doğrudan kopyalanıp ihtiyaca göre uyarlanabilir.

## Komutlar ve örnekler

Aşağıdaki örnekler teknik doğruluğu korumak için özgün komut ve kodu saklar.

```bash
    # Homebrew (macOS)
    brew install opencode

    # Or Go install
    go install github.com/opencode-ai/opencode@latest
    ```

```bash
    export ANTHROPIC_API_KEY="your API key"
    ```

```bash
    # OpenAI
    export OPENAI_API_KEY="your key"

    # DeepSeek
    export OPENAI_API_KEY="your key"
    export OPENAI_BASE_URL="https://api.deepseek.com/v1"
    ```

```bash
    npm install -g openyida
    ```
