# Codex kullanımı

Bu sayfa OpenYida içinde Codex kullanımı konusunu açıklar; amaç, kullanım akışı ve AI ile Yida uygulaması geliştirirken dikkat edilmesi gereken noktaları kapsar.

## Genel bakış

Bu belge OpenYida içinde Codex kullanımı konusunu; kullanım akışı, komutlar ve dikkat edilmesi gereken noktalarla açıklar.

## Önemli noktalar

- Gerçek bir projeye uygulamadan önce ana bağlamı anlamak için bu sayfayı kullanın.
- Komut adları, parametreler, kod ve bazı ürün adları doğru arama ve kopyalama için İngilizce bırakılmıştır.
- 宜搭 ile çalışırken yayımlamadan önce izinleri, organizasyonu ve ortamı kontrol edin.

## Kullanım

Bu dokümandaki adımları OpenYida CLI ve organizasyon ayarlarıyla birlikte izleyin. Aşağıdaki kod örnekleri doğrudan kopyalanıp ihtiyaca göre uyarlanabilir.

## Komutlar ve örnekler

Aşağıdaki örnekler teknik doğruluğu korumak için özgün komut ve kodu saklar.

```bash
    npm install -g openyida
    ```

```
    Help me log in to Yida
    ```

```
@Yida Help me create a project management system
```

```
Build an employee training management system on Yida, including a course schedule, registration form, and assessment scores table
```

```
Help me create a CRM system:
- Lead management: name, company, phone, source, follow-up status
- Customer profiles: linked to leads, industry, annual revenue, account manager
- Opportunity tracking: linked to customer, amount, stage, expected close date
```

```
Add a data analytics dashboard to my app showing this month's total opportunity amount and close rate
```

```
Help me configure an approval workflow: leave requests over 3 days require department manager approval
```
