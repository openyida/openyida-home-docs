# VS Code kullanımı

Bu sayfa OpenYida içinde VS Code kullanımı konusunu açıklar; amaç, kullanım akışı ve AI ile Yida uygulaması geliştirirken dikkat edilmesi gereken noktaları kapsar.

## Genel bakış

Bu belge OpenYida içinde VS Code kullanımı konusunu; kullanım akışı, komutlar ve dikkat edilmesi gereken noktalarla açıklar.

## Önemli noktalar

- Gerçek bir projeye uygulamadan önce ana bağlamı anlamak için bu sayfayı kullanın.
- Komut adları, parametreler, kod ve bazı ürün adları doğru arama ve kopyalama için İngilizce bırakılmıştır.
- 宜搭 ile çalışırken yayımlamadan önce izinleri, organizasyonu ve ortamı kontrol edin.

Bu dokümandaki adımları OpenYida CLI ve organizasyon ayarlarıyla birlikte izleyin. Aşağıdaki kod örnekleri doğrudan kopyalanıp ihtiyaca göre uyarlanabilir.
