## Định vị

Cấu hình truy cập công khai, liên kết chia sẻ nội bộ và trạng thái hiển thị điều hướng trang.

## Tác vụ thường gặp

- page access configuration
- organization sharing links
- navigation visibility
- post-change verification

## Gợi ý sử dụng

Treat public access as an impactful change and confirm the scope before enabling it.
