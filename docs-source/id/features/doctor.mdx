# Alat diagnostik

Halaman ini menjelaskan Alat diagnostik di OpenYida, termasuk tujuan, alur penggunaan, dan hal penting saat membangun aplikasi Yida dengan AI.

## Ikhtisar

Dokumen ini menjelaskan Alat diagnostik di OpenYida, termasuk alur penggunaan, perintah, dan hal yang perlu diperhatikan.

## Poin penting

- Gunakan halaman ini untuk memahami konteks utama sebelum menerapkannya di proyek nyata.
- Nama perintah, parameter, kode, dan beberapa nama produk tetap menggunakan bahasa Inggris agar mudah dicari dan disalin dengan benar.
- Saat bekerja dengan宜搭, periksa izin, organisasi, dan lingkungan sebelum publikasi.

## Penggunaan

Ikuti langkah dalam dokumen ini bersama OpenYida CLI dan konfigurasi organisasi. Jika ada contoh kode di bawah, contoh tersebut dapat disalin lalu disesuaikan dengan kebutuhan.

## Perintah dan contoh

Contoh berikut mempertahankan perintah dan kode asli untuk menjaga akurasi teknis.

```bash
openyida doctor
```

```bash
openyida doctor --fix
```

```bash
openyida doctor --report markdown
openyida doctor --report json
openyida doctor --report html
```

```bash
openyida doctor --monitor
```

```bash
openyida doctor env
```

```bash
# Node.js version
openyida doctor env --check node

# Playwright browsers
openyida doctor env --check playwright

# Login status
openyida doctor env --check auth

# Network connectivity
openyida doctor env --check network
```

```bash
openyida doctor app --app <appId>
```

```bash
# Check PRD files
openyida doctor app --check prd

# Check page source
openyida doctor app --check pages

# Check schema cache
openyida doctor app --check schema

# Check React Hooks
openyida doctor app --check hooks
```
