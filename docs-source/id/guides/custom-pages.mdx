# Halaman kustom

Halaman ini menjelaskan Halaman kustom di OpenYida, termasuk tujuan, alur penggunaan, dan hal penting saat membangun aplikasi Yida dengan AI.

## Ikhtisar

Dokumen ini menjelaskan Halaman kustom di OpenYida, termasuk alur penggunaan, perintah, dan hal yang perlu diperhatikan.

## Poin penting

- Gunakan halaman ini untuk memahami konteks utama sebelum menerapkannya di proyek nyata.
- Nama perintah, parameter, kode, dan beberapa nama produk tetap menggunakan bahasa Inggris agar mudah dicari dan disalin dengan benar.
- Saat bekerja dengan宜搭, periksa izin, organisasi, dan lingkungan sebelum publikasi.

## Penggunaan

Ikuti langkah dalam dokumen ini bersama OpenYida CLI dan konfigurasi organisasi. Jika ada contoh kode di bawah, contoh tersebut dapat disalin lalu disesuaikan dengan kebutuhan.

## Perintah dan contoh

Contoh berikut mempertahankan perintah dan kode asli untuk menjaga akurasi teknis.

```bash
openyida create-page <appType> "Dashboard"
openyida check-page project/pages/src/dashboard.oyd.jsx
openyida compile project/pages/src/dashboard.oyd.jsx
openyida publish project/pages/src/dashboard.oyd.jsx <appType> <formUuid>
```

```bash
openyida check-page project/pages/src/dashboard.oyd.jsx
openyida compile project/pages/src/dashboard.oyd.jsx
```

```bash
openyida update-form-config <appType> <formUuid> false "Dashboard"
```

```bash
openyida update-form-config <appType> <formUuid> true "Dashboard"
```

```bash
openyida build-page project/pages/src/dashboard.oyd.jsx --write
```
