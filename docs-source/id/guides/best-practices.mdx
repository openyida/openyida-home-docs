# Praktik terbaik

Halaman ini menjelaskan Praktik terbaik di OpenYida, termasuk tujuan, alur penggunaan, dan hal penting saat membangun aplikasi Yida dengan AI.

## Ikhtisar

Dokumen ini menjelaskan Praktik terbaik di OpenYida, termasuk alur penggunaan, perintah, dan hal yang perlu diperhatikan.

## Poin penting

- Gunakan halaman ini untuk memahami konteks utama sebelum menerapkannya di proyek nyata.
- Nama perintah, parameter, kode, dan beberapa nama produk tetap menggunakan bahasa Inggris agar mudah dicari dan disalin dengan benar.
- Saat bekerja dengan宜搭, periksa izin, organisasi, dan lingkungan sebelum publikasi.

## Penggunaan

Ikuti langkah dalam dokumen ini bersama OpenYida CLI dan konfigurasi organisasi. Jika ada contoh kode di bawah, contoh tersebut dapat disalin lalu disesuaikan dengan kebutuhan.

## Perintah dan contoh

Contoh berikut mempertahankan perintah dan kode asli untuk menjaga akurasi teknis.

```text Vague (Avoid)
Create a CRM
```

```text Detailed (Recommended)
Create a CRM with three related forms:
1. Lead Form — Fields: Name, Company, Phone, Email, Source (Dropdown: Referral/Website/Event/Cold Call), Status (Dropdown: New Lead/Contacted/Qualified/Disqualified), Assigned To (Member Selector)
2. Customer Form — Converted from leads, Fields: Company Name, Industry, Annual Revenue, Key Contact, Account Manager
3. Opportunity Form — Linked to customers, Fields: Opportunity Name, Amount, Stage (Dropdown: Proposal/Negotiation/Won/Lost), Expected Close Date, Notes
```
