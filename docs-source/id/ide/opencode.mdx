# Menggunakan OpenCode

Halaman ini menjelaskan Menggunakan OpenCode di OpenYida, termasuk tujuan, alur penggunaan, dan hal penting saat membangun aplikasi Yida dengan AI.

## Ikhtisar

Dokumen ini menjelaskan Menggunakan OpenCode di OpenYida, termasuk alur penggunaan, perintah, dan hal yang perlu diperhatikan.

## Poin penting

- Gunakan halaman ini untuk memahami konteks utama sebelum menerapkannya di proyek nyata.
- Nama perintah, parameter, kode, dan beberapa nama produk tetap menggunakan bahasa Inggris agar mudah dicari dan disalin dengan benar.
- Saat bekerja dengan宜搭, periksa izin, organisasi, dan lingkungan sebelum publikasi.

## Penggunaan

Ikuti langkah dalam dokumen ini bersama OpenYida CLI dan konfigurasi organisasi. Jika ada contoh kode di bawah, contoh tersebut dapat disalin lalu disesuaikan dengan kebutuhan.

## Perintah dan contoh

Contoh berikut mempertahankan perintah dan kode asli untuk menjaga akurasi teknis.

```bash
    # Homebrew (macOS)
    brew install opencode

    # Or Go install
    go install github.com/opencode-ai/opencode@latest
    ```

```bash
    export ANTHROPIC_API_KEY="your API key"
    ```

```bash
    # OpenAI
    export OPENAI_API_KEY="your key"

    # DeepSeek
    export OPENAI_API_KEY="your key"
    export OPENAI_BASE_URL="https://api.deepseek.com/v1"
    ```

```bash
    npm install -g openyida
    ```
