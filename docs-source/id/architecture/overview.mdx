## Perintah dan contoh

Contoh berikut mempertahankan perintah dan kode asli untuk menjaga akurasi teknis.

```
AI coding agent
  -> openyida CLI
  -> local project workspace
  -> Yida web APIs with cached login cookies
  -> Yida low-code app, form, page, report, or data result
```

```text
project/
  config.json
  pages/
    src/
    build/
    dist/
  .cache/
```

```bash
openyida create-page <appType> "Dashboard"
openyida check-page project/pages/src/dashboard.oyd.jsx
openyida compile project/pages/src/dashboard.oyd.jsx
openyida publish project/pages/src/dashboard.oyd.jsx <appType> <formUuid>
```

```bash
openyida env --json
openyida login --check-only --json
openyida env <setup|list|show|switch|add|remove>
```

```bash
openyida get-schema <appType> <formUuid>
```

```bash
openyida commands --json
```
